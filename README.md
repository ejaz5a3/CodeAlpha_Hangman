# CodeAlpha_Hangman

A simple text-based Hangman game built in Python as part of my
CodeAlpha Python Programming Internship (Task 1).

## How to Play
- The computer picks a random word from a list of 5 words.
- Guess one letter at a time.
- You can make 6 wrong guesses before the game ends.

## How to Run
1. Install Python 3
2. Run: `python hangman.py`

## Concepts Used
random module, while loop, if-else, strings, lists
